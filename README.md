# 👻 Phantom Launcher

Phantom is a personal Minecraft: Java Edition launcher with profiles,
mod loader support and a built-in client mod.

## Features
- Every Minecraft version: releases, snapshots and old versions
- Mod loaders: Vanilla, Fabric, Quilt, Forge and NeoForge
- Profiles with their own version, loader, memory and JVM settings
- Phantom Client mod (Fabric): FPS/CPS/coordinates HUD, keystrokes,
  zoom and toggle sprint
- Optional one-click install of performance mods from Modrinth

## Authentication
Phantom signs users in with their own Microsoft account using the
standard OAuth 2.0 authorization code flow with PKCE (public client,
no client secret). It verifies Minecraft: Java Edition ownership and
launches the game with the user's own session. Tokens are stored only
on the user's computer. No account data is collected or sent anywhere.
Offline and cracked accounts are not supported.
